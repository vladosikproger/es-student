# 3.2.1 — Индикатор записи

Проект `321-audio-recorder` создан на основе `311-adc`. В этом задании встроенный LED (GPIO25) переключается повторяющимся будильником SDK, а не задачей суперцикла.

## Команды

- `timer_blink_start <period_ms>` — запустить мигание, период переключения 10..60000 мс.
- `timer_blink_stop` — остановить мигание и вывести число переключений.

Пример проверки одновременной работы: `timer_blink_start 250`, затем `pi_start 3000000`, `uptime`, `pi`, `timer_blink_stop`.

Две кнопки GP15 и GP14, измерение напряжения и температуры, телеметрия и прежние команды сохранены. Во время таймерного мигания GPIO25 принадлежит callback таймера; для исключения конфликта задача LED переводится в состояние OFF.

## Сборка

Запускать из этой папки проекта:

```powershell
cmake -G Ninja -S . -B build
ninja -C build
```

Файл прошивки: `build\321_audio_recorder.uf2`.

## Проверка и лог

Закрой Serial Monitor, затем выполни:

```powershell

```

## п3.2.2 — Захват по таймеру

Добавлен конечный захват отсчётов GP26 по повторяющемуся будильнику:

- `cap_start <N> <period_us>` — снять от 1 до 2000 отсчётов с периодом не менее 10 мкс;
- `cap_dump` — вывести коды АЦП, минимум/максимум фактических интервалов и долю времени внутри обработчика.

Во время захвата команды `get_voltage`, `get_temp` и `tm_start` отвечают `error: adc busy`; запустить захват во время телеметрии также нельзя.

Проверка и лог:

```powershell
python check-3-2-2.py
```

Скрипт создаёт `device-3-2-2.log`. Перед запуском закрой Serial Monitor, чтобы освободить COM-порт.


## п3.2.3 — Захват блока через DMA

Добавлен захват блока отсчётов GP26 без участия ядра в каждом измерении:

- АЦП работает в непрерывном режиме с частотой 44 100 Гц;
- FIFO АЦП формирует запрос `DREQ_ADC` для DMA;
- DMA переносит 16-битные значения из FIFO в `block_samples`;
- прерывание `DMA_IRQ_1` отмечает завершение блока;
- задача `block-task` передаёт готовый массив callback-функции в суперцикле;
- команда `dma_cap <N>` выводит фактическое и расчётное время, минимум, максимум и среднее значение отсчётов.

Новые внешние детали не требуются. Для этого задания GP26 оставляется свободным: значения АЦП будут плавать, поскольку мы проверяем прежде всего захват и временные характеристики.

Примеры команд:

```text
dma_cap 1000
dma_cap 4410
dma_cap 8192
```

Проверка и лог:

```powershell
python check-3-2-3.py
```

Скрипт создаёт `device-3-2-3.log`. Перед запуском закрой Serial Monitor, чтобы освободить COM-порт.
