ГОТОВЫЕ ФАЙЛЫ ДЛЯ ПРИЁМКИ п2.3.8

Содержимое архива расположено относительно корня репозитория es-student:
  231-firmware-template/CMakeLists.txt
  231-firmware-template/firmware.h
  231-firmware-template/README.md
  231-firmware-template/logic/api/api.c
  231-firmware-template/logic/api/api-callbacks.c

Скопируйте файлы из папки 231-firmware-template в одноимённую папку своего
проекта с сохранением структуры каталогов. Перед заменой можно сохранить копии
текущих файлов.

Что изменено:
1. В обычной сборке включено профилирование: PROFILING_ENABLED=1.
2. Команда info печатает ровно восемь строк с полями из приложения Б.
3. Поля manufacturer/part выводятся минимум с тремя/четырьмя hex-цифрами.
4. Исправлены точные тексты ошибок для pi_start 0 и led_period 0.
5. Исправлен ответ profiling_reset: "profiling reset".
6. Парсер чисел отвергает нецифровые знаки, в том числе +5, -1, 0x10 и 5x.
7. help выводит свою строку "help list of commands" первой; порядок команд
   согласован с перечнем приложения Б.
8. В README добавлен значок проверки 2.3.8.

После копирования из PowerShell (из 231-firmware-template):
  cmake -S . -B build
  cmake --build build --clean-first

Затем загрузите build\231_firmware_template.uf2 на плату и выполните:
  python .\check-2-3-8.py

ВНИМАНИЕ: аппаратную часть (светодиод и кнопку) всё равно нужно проверить
вручную. Сам файл исходников не подтверждает прохождение теста на плате.
