# П3.1.5 — порядок выполнения с сохранением двух кнопок

## Что изменено в этой версии

1. Pico устанавливается непосредственно в breadboard поперёк центральной канавки.
2. RC-цепь `1 кОм + 1000 мкФ` устанавливается напрямую в свободные отверстия узлов GP22, GP26 и AGND.
3. Сохранены две кнопки: GP15 и GP14. В отличие от исходной прошивки 311-adc с одной кнопкой, эта версия прошивки инициализирует и опрашивает обе кнопки.
4. Потребуются короткие перемычки только от GPIO/земли к кнопкам, если кнопки остаются в нижней части макетки.

## Поведение кнопок

- Кнопка 1, GP15: коротко нажать — переключить LED между OFF, ON, BLINK; удерживать около 1 секунды — принудительно включить BLINK.
- Кнопка 2, GP14: короткое нажатие переключает период мигания 1000 → 250 → 500 → 1000 мс.
- Команда `button` показывает состояния и количество нажатий обеих кнопок.

## Порядок действий

1. Снимите USB и установите Pico поперёк центральной канавки USB-разъёмом к верхнему краю макетки.
2. Не трогайте расположение двух тактовых кнопок без необходимости. Оставьте их ниже Pico, в свободной части макетки.
3. По документу `ПОЛНАЯ_СБОРКА_С_ДВУМЯ_КНОПКАМИ.md` соедините первую кнопку с GP15, вторую с GP14; вторые контакты обеих кнопок соедините с GND. Используйте короткие перемычки.
4. Вставьте резистор между GP22 и GP26; электролитический конденсатор — плюсом к GP26, минусом к AGND.
5. До USB проверьте отсутствие коротких замыканий и полярность конденсатора.
6. Распакуйте обновление в корень `C:\Repositories\pico\es-student`.
7. Соберите прошивку:

```powershell
cd C:\Repositories\pico\es-student\311-adc
cmake -G Ninja -S . -B build
ninja -C build
```

8. Запишите `build\311_adc.uf2` через BOOTSEL.
9. Проверьте в Serial Monitor:

```text
button
charge_on
charge_off
```

Нажатия кнопок должны менять состояние светодиода и период мигания. Команды `charge_on` / `charge_off` должны отвечать `charge: on` и `charge: off`.
10. Закройте Serial Monitor, установите Python-зависимости и запустите:

```powershell
python -m pip install -r requirements-telemetry.txt
python rc.py --r 1 --c 1000
```

11. После получения `rc.csv`, `rc.png` и `rc.log` отправьте работу в Git:

```powershell
cd C:\Repositories\pico\es-student
git add --all
git commit -m "Сделана п3.1.5"
git push
```

## Физическая безопасность

- GP22 и GP26 — только логика 0–3,3 В. Никогда не подавайте на них 5 В.
- Минус электролитического конденсатора — к AGND; плюс — к GP26.
- Не соединяйте GP14 и GP15 между собой.
- У каждой кнопки должен быть отдельный GPIO, а второй контакт — GND.
- Перед перестановкой деталей отключайте USB.
