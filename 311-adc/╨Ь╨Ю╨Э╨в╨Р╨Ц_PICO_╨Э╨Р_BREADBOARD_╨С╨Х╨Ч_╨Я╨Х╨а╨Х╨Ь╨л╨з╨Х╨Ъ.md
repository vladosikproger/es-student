# Уточнение по прямой установке Pico

Этот файл описывает только механическую установку Pico и RC-цепи. Для полной конструкции с сохранением обеих кнопок обязательно используйте основной документ:

**`ПОЛНАЯ_СБОРКА_С_ДВУМЯ_КНОПКАМИ.md`**

В полной конструкции GP15 остаётся подключён к кнопке 1, GP14 — к кнопке 2. Для двух кнопок предусмотрены короткие перемычки от их нижнего расположения к соответствующим GPIO и общему GND. Полностью убирать эти перемычки нельзя, если кнопки физически остаются ниже Pico: горизонтальные группы breadboard не соединены между разными строками.

RC-цепь (резистор между GP22 и GP26, конденсатор между GP26 и AGND) подключается непосредственно через свободные отверстия тех же строк Pico и не требует отдельных проводов.
