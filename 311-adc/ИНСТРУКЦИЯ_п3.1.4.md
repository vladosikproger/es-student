# П3.1.4 — инструкция по запуску

## Что добавлено

- `get_telemetry.py` — готовый скрипт из задания: находит плату по USB VID/PID, включает поток `tm_start`, принимает строки `tm:`, сохраняет `telemetry.csv` и строит `telemetry.png`.
- `requirements-telemetry.txt` — Python-зависимости.
- `.github/workflows/check-3-1-4.yml` — workflow автоматической проверки (лежит в корне репозитория, а не внутри `311-adc`).
- В `README.md` добавлен значок проверки 3.1.4.

Прошивка микроконтроллера не меняется: нужен уже работающий firmware проекта `311-adc` из п3.1.3 с командами `tm_start` и `tm_stop`.

## Установка в Windows PowerShell

Перейдите в каталог проекта:

```powershell
cd C:\Repositories\pico\es-student\311-adc
```

Установите библиотеки в тот Python, которым будете запускать скрипт:

```powershell
python -m pip install -r requirements-telemetry.txt
```

`pyserial` нужен для открытия USB CDC-порта как COM-порта. `matplotlib` нужен для построения графика. Если `pyserial` уже установлен из предыдущих лабораторных, переустановка не повредит.

Закройте PuTTY, Thonny, терминал или другой монитор последовательного порта: одновременно два приложения обычно не могут владеть одним COM-портом.

Запустите стандартный сбор: 10 секунд, период телеметрии 100 мс:

```powershell
python get_telemetry.py
```

Скрипт сам ищет Pico SDK CDC устройство с VID `0x2E8A` и PID `0x000A`. Порт COM3 вручную задавать не нужно: он обнаруживается автоматически.

Вариант: собрать 30 секунд с периодом 50 мс:

```powershell
python get_telemetry.py --seconds 30 --period 50
```

После сбора рядом со скриптом появятся:

- `telemetry.csv` — таблица измерений;
- `telemetry.png` — график напряжения и температуры по времени.

Проверить построение графика без подключённой платы:

```powershell
python get_telemetry.py --plot telemetry.csv
```

В этом режиме скрипт только читает уже сохранённый CSV и создаёт `telemetry.png`. Плату искать и открывать COM-порт он не будет.

## Что нужно проверить перед коммитом

1. В CSV первая строка должна быть `time_s,voltage_v,temp_c`.
2. В файле должно быть около 100 записей для стандартного 10-секундного сбора с периодом 100 мс (точное число может немного отличаться из-за старта/остановки).
3. Первый `time_s` равен `0.000000`, последующие времена возрастают примерно на 0.1 секунды.
4. PNG содержит два графика: напряжение GP26 и температуру кристалла.
5. Команда с `--plot` работает без платы.

Физические данные CSV и PNG должны быть получены с вашей платы запуском скрипта. Архив не подменяет их искусственно созданными измерениями.
