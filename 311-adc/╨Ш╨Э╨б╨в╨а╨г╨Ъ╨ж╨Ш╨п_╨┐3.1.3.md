# Как распаковать, собрать и проверить п3.1.3

## 1. Распаковка

Распакуй содержимое ZIP **в корень репозитория**, то есть в:

```text
C:\Repositories\pico\es-student
```

Не распаковывай архив внутрь `311-adc`: внутри ZIP уже есть папка `311-adc`, а также путь `.github/workflows`.

Архив обновит проект `311-adc` и добавит workflow `check-3-1-3.yml`. Общая папка `libs` не входит в ZIP, потому что задание использует уже имеющиеся библиотечные модули репозитория.

## 2. Сборка через PowerShell и Ninja

Открой PowerShell и выполни:

```powershell
cd C:\Repositories\pico\es-student\311-adc
cmake -G Ninja -S . -B build
ninja -C build
```

Первая команда переходит в папку проекта. Вторая настраивает сборку CMake с генератором Ninja. Третья запускает компиляцию.

При успешной сборке появится файл прошивки:

```text
build\311_adc.uf2
```

## 3. Запись прошивки на Pico

1. Отключи плату от USB.
2. Зажми BOOTSEL и подключи USB-кабель.
3. Отпусти BOOTSEL после появления накопителя `RPI-RP2`.
4. Скопируй `build\311_adc.uf2` на накопитель.
5. Дождись перезагрузки платы.

## 4. Проверка телеметрии вручную

Открой терминал, подключись к USB CDC COM-порту платы и проверь команды:

```text
tm_start
```

Ожидаемый ответ — `telemetry: started, period 100 ms`, после чего начнут поступать строки `tm: ...`.

Проверь другой период:

```text
tm_start 500
```

Затем останови поток:

```text
tm_stop
```

Проверь обработку ошибочных аргументов:

```text
tm_start 5
tm_start 10 20
tm_start 5x
```

## 5. Автоматический скрипт и лог

Перейди в папку `311-adc` и запусти:

```powershell
python check-3-1-3.py
```

Скрипт автоматически найдёт Pico по USB VID/PID, отправит набор команд, прочитает ответы и сохранит:

```text
device-3-1-3.log
```

Если Python сообщит, что модуль `serial` не найден, установи PySerial:

```powershell
python -m pip install pyserial
```

Перед запуском закрой другие программы, которые уже открыли COM-порт платы.

## 6. Отправка на GitHub

Команды выполняются из корня репозитория:

```powershell
cd C:\Repositories\pico\es-student
git status
git add --all
git commit -m "Сделана п3.1.3"
git push
```

После отправки открой вкладку **Actions** репозитория и найди workflow **3.1.3 Телеметрия измерений**. Задание считается принятым автоматической системой, когда проверка завершится успешно.

## 7. Что лежит в архиве

- Обновлённый проект `311-adc` с новой задачей `logic/telemetry-task`.
- Команды `tm_start` и `tm_stop`, а также вывод строк телеметрии.
- Вызов задачи и секундомер `telemetry` в `main.c`.
- `check-3-1-3.py` и workflow `.github/workflows/check-3-1-3.yml`.
- Подробный конспект `ТЕОРИЯ_п3.1.3_телеметрия_RP2040.md`.

Файл `device-3-1-3.log` намеренно не включён: его нужно получить настоящим запуском скрипта на твоей плате, а не подменять заранее заготовленным примером.
